PixelRunner 本地帮助中心

PixelRunner 连接 RunningHub，从第一次配置到返图

这份文档按 RunningHub 当前官网入口和 PixelRunner 的实际使用顺序整理：先到消费级 API 控制台复制 API Key，再从 AI 应用页找到合适应用，接着在 Photoshop 里捕获图片、运行任务、查看返图。后面也放了资料包备份、快捷入口和常见失败排查，适合新手上手，也适合出问题时快速查。

按步骤开始 保存和查看 运行失败排查

先确认这 4 件事

  • RunningHub 账号
    需要能登录官网，并能进入消费级 API 控制台复制 API Key。
  • 钱包有 RH 币
    消费级 API 会消耗账号 RH 币，网站任务和 API 调用共享并发限制。
  • Photoshop 已打开文档
    需要捕获当前文档或选区时，必须先打开图像。
  • 准备一个 AI 应用
    从 RunningHub 的 AI 应用页下翻到广场，或直接搜索需要的应用。

First Run

第一次使用：按这个顺序做

第一次配置不要跳步。只要 API Key、余额、应用三件事通了，后面就是正常填参数运行。

约 5 分钟

在消费级 API 控制台复制 API Key

打开 RunningHub 的 消费级-会员 API 控制台，登录账号后进入密钥区域，复制自己的 API Key。当前直达地址是 https://www.runninghub.cn/enterprise-api/consumerApi。

  • 目前官网右上角头像菜单里没有 API 控制台入口，建议直接使用上面的控制台网址。
  • 消费级 API 调用会消耗账号里的 RH 币；如果看不到密钥或调用失败，先确认账号是否具备对应 API 权益。
  • 如果 API Key 失效，回官网 API 控制台重新复制或重置新的 Key。
  • API Key 属于敏感信息，不建议发到公开群聊或截图里。
打开 API 控制台 查看官方 API 文档

充值或确认钱包余额

PixelRunner 调用的是 RunningHub 云端任务。消费级 API 会消耗账号 RH 币，且官网运行任务和 API 调用任务共享同一套并发限制。建议第一次运行前先在官网确认余额，避免插件里看起来提交了，但云端直接因为余额不足失败。

经验判断：如果一点击运行就很快失败，优先查余额、会员/API 权益和 API Key；如果等了很久才失败，再看应用拥挤、并发限制、网络或内容审核。

在插件设置里保存 API Key

回到 PixelRunner，打开 设置。在 API 设置 中填写 RunningHub API Key 和 API 档案名称，然后点击 保存设置。

  • 有多个账号时，可以用“新增”创建多个 API 档案，例如“主账号”“客户项目 A”。
  • 保存后，工作台右上角会尝试显示余额和 RH 币。
  • 看不到余额时，先确认 Key 是否正确，再确认网络是否能访问 RunningHub。
保存在哪里：插件会把 API 档案保存在 Photoshop 插件宿主的本地存储中。换电脑、重装插件、清理宿主数据后，需要重新导入资料包或重新填写。

在 RunningHub 找到要用的 AI 应用

打开 https://www.runninghub.cn/ai-apps。页面前面通常是 精选应用，继续往下翻会看到 AI应用广场；也可以直接用页面里的搜索或筛选找到目标应用。

  • 优先选择自己在网页端能正常打开、能手动试跑的应用。
  • 打开应用详情页后，浏览器地址通常类似 https://www.runninghub.cn/ai-detail/1937084629516193794。
  • 详情页末尾那串数字就是 webappId / 应用 ID；PixelRunner 可以直接粘完整链接，也可以只粘这串数字。
  • 如果官网入口从 AI 应用 跳到新版页面，仍然以详情页链接里的 ai-detail/数字 为准。
打开 AI 应用页

把 AI 应用保存到 PixelRunner

回到 PixelRunner，进入 工作台，在“选择应用”区域点击 切换，再点击弹窗里的 添加应用。把 RunningHub 应用 ID 或完整应用链接粘进去，点击 解析，确认名称后点击 保存应用。

  • 解析成功后，应用会出现在“已保存应用”列表中。
  • 应用保存后会自动切换到工作台，表单会按该应用的输入项生成。
  • 如果你保存了很多应用，可以在 设置 / 高级设置 中打开“仅文字的高密度列表”，应用切换面板会更紧凑。
解析失败先看四件事：API Key 是否已保存，账号是否有 API 调用权益，应用 ID 是否复制错，当前网络是否能直连 RunningHub。

Daily Workflow

日常运行：从 Photoshop 到返图

这部分对应你每天最常用的流程。核心是先选应用，再给图片字段捕获当前文档或选区，最后开始运行。

工作台

1. 先打开 Photoshop 文档

需要处理哪张图，就先在 Photoshop 中打开它。如果只想处理局部，先用选区工具框选区域；插件会尽量按源文档或选区把结果自动贴回。

2. 选择已保存应用

工作台左上“选择应用”区域点击 切换。你可以搜索应用、添加应用、编辑应用，或拖动应用卡片调整顺序。应用很多时，可以去高级设置打开高密度文字列表，同屏更容易扫到目标应用。

3. 填写动态表单

表单会根据应用结构显示图片、文本、数字、开关、选项等字段。必填项没填时，开始运行会被拦下并提示缺少哪些字段。

4. 点击图片字段捕获

图片输入字段通常可以点击捕获 Photoshop 当前文档或当前选区。捕获成功后，日志会显示“已捕获并写入字段”。

5. 点击开始运行

点击 开始运行 后，任务卡片会显示提交、运行、完成或失败状态。插件会按设置里的轮询间隔、超时时间和最大并发数等待 RunningHub 返回结果。

6. 查看返图和日志

任务完成后，插件会记录结果地址，并尝试自动贴回 Photoshop。若 Photoshop 正忙，插件会排队稍后重试；如果贴回失败，可以从运行日志或任务卡片里继续排查。

运行前检查
已保存 API Key、已选择应用、必填项已填、Photoshop 文档已打开。
局部处理检查
先在 Photoshop 做选区，再捕获图片字段，返图会尽量按原选区贴回。
并发检查
达到最大并发数时，需要等部分任务完成后再继续发送。
网络检查
RunningHub 任务建议关闭代理、加速器或异常网络转发。

Save And Review

保存、查看、备份分别在哪里

用户最容易混淆的是“保存设置”“保存应用”“保存模板”“导出资料包”。这几个保存的是不同东西。

重点查阅
你想保存什么 在哪里操作 保存后怎么查看 注意事项
RunningHub API Key 设置 / API 设置 / 保存设置 API 档案下拉框、API 档案标签、工作台余额 本地存储。换电脑或清理数据后要重新填写。
AI 应用 RunningHub AI 应用页复制详情链接或 ID，然后在工作台 / 切换 / 添加应用 / 保存应用 工作台“切换”弹窗的已保存应用列表，或设置页应用列表 解析依赖 API Key、API 权益和网络。保存后不会影响 RunningHub 官网应用本身。
应用切换显示密度 设置 / 高级设置 / 应用切换密度 / 保存设置 工作台“切换”弹窗会按图片卡片或文字高密度列表显示 只影响本地显示方式，不影响已保存应用和 RunningHub 官网应用。
提示词模板 设置 / 提示词模板 / 保存模板，或工作台模板弹窗中新建预设 工作台提示词字段的模板选择器、设置页模板列表 建议按分类整理，标题写清用途，方便搜索。
快捷入口 工作台选好应用并填好非图片参数后，点击“快捷” 工作台应用选择器中的“快捷入口”模式 快捷入口运行时仍需要先在 Photoshop 中框选区域。
整套配置备份 设置 / 资料包导入导出 / 导出资料包 导出的 JSON 文件可以再用“导入资料包”恢复 用于换电脑、分享配置、恢复应用和模板最方便。
推荐备份习惯：每次整理完一批应用或提示词模板后，去设置页点一次 导出资料包。这比只记应用 ID 更稳，因为它会一起保存应用、提示词分类、提示词预设和快捷入口。

Prompt Templates

提示词模板：少重复输入，多复用

如果同一套风格、修图要求、负面词经常用，就把它保存成模板。以后从工作台直接选择，比每次复制粘贴稳很多。

效率工具

创建模板

进入 设置，展开 提示词模板。选择所属分类，填写模板标题和模板内容，点击 保存模板。

在工作台使用模板

当当前应用存在提示词字段时，工作台会提供模板选择入口。选择一个或多个模板后，点击应用模板写入当前字段。

从当前字段保存为预设

如果你在工作台临时写出了一段好用的提示词，可以在模板弹窗中新建预设，把当前字段内容保存下来。

命名建议

模板标题建议写成“用途 + 风格 + 版本”，比如 人像精修-自然皮肤-v2、电商图-白底增强。后期模板多了以后，搜索会轻松很多。

Quick Entry

快捷入口：把常用流程变成一键动作

快捷入口会保存当前应用和全部非图片参数。适合固定风格、固定应用、每天重复跑的工作。

高频工作

怎么创建

在工作台选择应用，填好提示词、选项、强度等非图片参数，点击“选择应用”区域右侧的 快捷，输入名称并保存。

怎么运行

先在 Photoshop 中框选要处理的区域，再在应用选择器中切换到 快捷入口，点击对应入口运行。

为什么要求选区

快捷入口会自动捕获当前选区作为图片输入。如果没有打开文档或没有选区，插件会提示先打开文档或先框选区域。

什么时候重建

如果应用 ID 改了、字段结构变了、提示词参数大幅调整，建议重新保存快捷入口，避免引用旧字段。

Troubleshooting

运行失败时按这个顺序排查

不要一失败就重装插件。大部分问题可以从余额、Key、应用拥挤、图片内容、网络环境这几项定位。

故障恢复

余额不足

工作台右上余额为空或过低时，先去 RunningHub 官网确认 RH 币和消费级 API 权益。余额不足是最常见的失败原因之一。

API Key 未保存或失效

报错里出现 API Key missing、param apikey is required，回设置页重新粘贴 Key 并保存设置。

热门应用或并发限制

热门应用在高峰时段可能排队、超时或偶发失败；消费级 API 也会和网页端任务共享并发限制。可以稍后重试、降低并发，或换轻量应用。

图片内容被审核拦截

如果参数没问题但任务稳定失败，尝试换一张图片。云端审核拦截通常不是插件本地能解决的。

代理、加速器或网络转发

关闭代理、加速器、异常 DNS 或网络转发后重试。若必须使用代理，至少确认浏览器能正常打开 API 控制台和 AI 应用详情页。

Photoshop 正忙导致返图延迟

如果任务已完成但没有马上贴回，可能是 Photoshop 正在液化、保存或其他模态操作。插件会尝试稍后自动重试。

先看工作台任务卡片

任务卡片会显示提交中、运行中、后台追踪、完成、失败、取消等状态。失败时先看卡片上的简短原因。

再看运行日志

工作台下方的运行日志会记录捕获、提交、任务 ID、结果地址、贴回状态等信息。排查时可以把关键日志复制给维护者。

最后去 RunningHub 官网核对

如果插件显示任务 ID，但本地等待超时，说明远端任务可能还在运行。可以去 RunningHub 消费级 API 控制台查看调用记录，或在官网任务记录里搜索任务状态。
